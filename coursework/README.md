# CSCI 341 ? Database Systems

Selected solutions from my 2023 Database Systems coursework at Nazarbayev University. The two assignments use different examples. The first models a recruitment portal. The second implements a caregiver database, which I later developed into the [Django job board and SQLAlchemy lab](../README.md).

| Assignment | What it demonstrates | Where to start |
| --- | --- | --- |
| 01 ? Recruitment database design | Enhanced ER and UML class diagrams, relationship cardinality, and advert specialization | [Design notes and submitted diagram](assignment_01_recruitment/) |
| 02 ? Caregiver database implementation | Relational keys, inserts and updates, cascading deletes, joins, aggregation, and reporting | [Exercises and runnable solutions](assignment_02_caregiver/) |

The exercise descriptions are summaries. The submitted design is presented as a PDF and an editable diagram. The database scripts are adapted for an isolated demo using synthetic data. See each assignment for the changes made for this repository.
